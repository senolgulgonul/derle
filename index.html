How to use Derle

Quick start. Type C code on the left (or pick one from Examples, or Open a .c file), press Compile, then Run. Anything your program reads with scanf/getchar must be typed into the Input (stdin) box before running. Output, compiler errors and the exit code appear in the Console. If you edit the code, compile again before running.

Sharing code with a link. Derle can open any C file that is reachable by URL, using the ?src= parameter:

https://senolgulgonul.github.io/derle/?src=<raw file URL>

For a file on GitHub: open it on github.com, press the Raw button, copy that address, and append it after ?src=. Example:

https://senolgulgonul.github.io/derle/
  ?src=https://raw.githubusercontent.com/senolgulgonul/derle/main/examples/derle-test.c

Anyone opening that link gets your code in the editor, one Compile away from running — ideal for sharing exercises or asking for help.

Good to know. The first visit downloads the compiler once (~23 MB); afterwards it loads from cache. Programs are stopped after 10 seconds (usually an infinite loop). Everything runs locally in your browser — your code never leaves your machine.
